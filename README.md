# أسرار أعماق البحار

تجربة ويب سينمائية عربية من ثمانية فصول، تروي رحلة إنشاء الموقع من الفكرة الأولى حتى لحظة الإطلاق.

## التشغيل

الموقع ثابت بالكامل (HTML/CSS/JavaScript) ولا يحتاج إلى بناء أو تثبيت حزم.

- افتح `index.html` مباشرة في المتصفح.
- أو شغّل خادماً محلياً للحصول على أفضل تجربة:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## النشر

يمكن نشر المجلد كما هو على أي استضافة مواقع ثابتة:

- **Netlify / Vercel:** اسحب المجلد إلى لوحة النشر، أو اربطه بالمستودع دون أمر بناء.
- **GitHub Pages:** ارفع الملفات إلى الفرع الرئيسي ثم فعّل Pages من إعدادات المستودع.
- **استضافة تقليدية:** ارفع الملفات إلى `public_html` أو ما يعادلها.

## المميزات

- ثماني شرائح كاملة الشاشة مع انتقالات سينمائية وحركة خلفيات بطيئة.
- أزرار السابق والتالي، مؤشر رقم الشريحة، شريط تقدم، ونقاط تنقل سريعة.
- فهرس فصول تفاعلي مع دعم التركيز ولوحة المفاتيح.
- دعم السحب على الهاتف والأسهم ومسافة و Page Up/Down و Home/End.
- فقاعات وكائنات دقيقة متحركة على Canvas، مع احترام إعداد تقليل الحركة.
- تصنيف لوني سينمائي للصور، ومؤثرات ضوئية، وحبيبات خفيفة.
- متوافق مع الجوال والكمبيوتر، مع دعم RTL كامل وخطوط عربية محلية.
- مشاركة الرحلة أو نسخ رابط الشريحة الحالية.
- صور وخطوط محلية، فلا تعتمد الصفحة على شبكة خارجية أثناء العرض.

## الصور

الصور الفوتوغرافية من [Unsplash](https://unsplash.com/license) وتُستخدم وفق ترخيص Unsplash. أُعيد تلوينها ودمجها بصرياً داخل التصميم.

## إعدادات مفيدة

- الألوان والمسافات الأساسية في أعلى `styles.css` ضمن `:root`.
- محتوى كل شريحة ونصوصها في `index.html`.
- بيانات الانتقال والمؤقتات والقائمة في `script.js`.
- يمكن تحميل الموقع على شاشة عرض كاملة، ويدعم الروابط المباشرة مثل `#slide-5`.
